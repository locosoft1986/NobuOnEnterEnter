# 信長回車精靈3.0



\## 本程式基於AGPL v3協議，也即修改代碼分發必須開源。



\## Release下載，默認只提供Win64，dotNet 8.0



\- \[Release頁面](https://github.com/locosoft1986/NobuOnEnterEnter/releases/tag/3.0.0)



\## 安裝



信長之野望Online回車精靈，先在上面Release頁面下載最新zip包



解壓放在喜歡的目錄下，最好目錄名都是英文， 右擊NobuOnEnterEnter.exe“以管理員方式啓動”



可以右擊發送快捷方式到桌面





\## 使用方法

功能很簡單，點擊“添加視窗”等10秒，此時點擊要添加的信長之野望的視窗，等倒計時結束會添加到右邊的列表中



在右邊的列表中選中任意視窗，點擊左側“啓動選擇視窗”即可開啓不斷發送回車指令到對應視窗，視窗可以沒有焦點狀態



底下還可以設置每個回車的間隔時間。



在單獨啓動某個視窗時，每個視窗都可以在啓動前設置各自的間隔



但如果是點擊全部啓動，那所有視窗的間隔都是一樣的
