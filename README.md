## 使用方法

功能很簡單，點擊“添加視窗”等10秒，此時點擊要添加的信長之野望的視窗，等倒計時結束會添加到右邊的列表中



在右邊的列表中選中任意視窗

選中窗口後左側會有一個下拉可以選擇不同模式，目前支持：

### 1. 連續回車模式
點擊左側下方“啓動選擇視窗”即可開啓不斷發送回車指令到對應視窗，視窗可以沒有焦點狀態

可以設置每個回車的間隔時間。

適合場景：
1. 你想要在信長之野望Online中生產
2. 你想要在信長之野望Online中采集

次模式不會檢測比如材料是否用完，或者背包是否已滿

### 2. 夢幻冥宮
在進入夢幻冥宮之後，召喚你的英傑或家臣。

#### 把選擇對象按end鍵切換至NPC

在左側輸入一場戰鬥你自己預估的時間，單位是秒。 要注意的是隨著層數增加，預估的時間需要適當增加，否則時間軸會錯位。

常見的錯位現象是：
1. 寶箱還沒有開完就開始前進後退
2. 在戰鬥快結束時，右下角進入攻擊/選技能菜單，或者進去求援輔助菜單

如果求穩，想通宵離機的話推薦60秒，我測下來1500層以下沒有問題，隨著爬樓層數越高，需要適當增加層數


### 3. 夢幻冥泉
在進入夢幻冥宮之後，召喚你的英傑或家臣。

#### 把選擇對象按end鍵切換至NPC

在左側輸入一場戰鬥你自己1-9層預估的時間，單位是秒。 要注意的是隨著層數增加，預估的時間需要適當增加，否則時間軸會錯位。

在左側輸入最終王的預估時間，單位是秒。

常見的錯位現象是：
1. 寶箱還沒有開完就開始前進後退
2. 在戰鬥快結束時，右下角進入攻擊/選技能菜單，或者進去求援輔助菜單

如果求穩，想通向離機的話， 1-9層推薦60秒，最終王設置成120秒。我測下來400層以下沒有問題，隨著爬樓層數越高，需要適當增加層數
